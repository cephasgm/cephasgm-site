Water-Energy IoT Systems

We build intelligent IoT systems that optimise water pumping using real-time electricity tariff data, water levels, and leak detection. Using an ESP32 microcontroller with ultrasonic and current/energy sensors, and a cloud backend (Flask, MySQL), the system automates pumps during off-peak hours — saving up to 30% energy and preventing water waste. Includes a reactive dashboard, manual override, email alerts, CSV reports, and PWA.

Related Projects:

  • Smart Integrated Water-Energy — Live system · View live
  • ESP32 firmware & Flask API — Open source (available on request)
  • Tariff-aware pump controller — Up to 30% energy savings worldwide

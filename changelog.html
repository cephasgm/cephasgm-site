Release 2026.09 · Security Hardening Role-based access control across the entire portalCurrent
September 2026
✓ Added
  • Firestore Security Rules — server-side enforcement of admin and client access, with immutable audit logging collection ready
  • Storage Security Rules — file upload/download access control, ready to activate when Cloud Storage is enabled
  • Public Architecture page — full engineering stack documented with links to official documentation
  • Public Changelog page — this page, for transparent release tracking
  • Skip-to-content links — WCAG 2.1 Level A compliance on all site pages
  • Organization schema (JSON-LD) — structured data for search engines and AI systems
  • sitemap.xml and robots.txt — explicit crawler guidance with AI bot permissions
◆ Changed
  • Admin Dashboard — now shows the full portfolio of projects across all users, not just the admin's own
  • Client Dashboard — role-aware heading and scope labels clarify what each user is seeing
  • Main site navigation — brand mark now serves as home; Home link removed for cleaner hierarchy
  • Water-Energy system — reframed for global deployment; no longer limited to any region
◎ Fixed
  • Admin visibility bug — admin was only seeing their own projects because the query was filtered to their UID. Now correctly shows all projects via role-based query
  • Login redirect loop — authenticated users landing on the login page are now auto-routed to their correct destination
  • Modal focus trapping — keyboard users can no longer tab outside an open modal
⚠ Security
  • Credentials removed from public login page — demo credentials are no longer shown to visitors
  • Search engine de-indexing — login page marked with noindex, nofollow
  • Hardened HTML escaping — extended sanitisation across dashboard, downloads, and accounting pages

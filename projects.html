Smart Integrated Water-Energy Management System

Overview

An intelligent IoT system that optimises water pumping using real-time electricity tariff data, water level, and leak detection. Built on ESP32, Flask, MySQL, and a reactive JavaScript dashboard — saving up to 30% energy by pumping only during off-peak hours. Supports two hardware modes (Basic current sensors, or Modern flow + whole-house energy meter). Includes AI assistant, remote manual control, billing reports, and PWA — deployable for utilities and industrial facilities worldwide.

Key Features:

  • Real-time water level, flow, pressure & energy analytics
  • Tariff-based pump automation (off-peak optimisation)
  • AI-based leak detection & email alerts
  • Manual override & historical trends
  • CSV report export & simulation speed control

EchoShield — AI Drone Detection & Countermeasure Platform

Overview

A hardware-assisted AI drone detection and countermeasure platform. Combines an Arduino UNO sensor array (HC-SR04 ultrasonic), a Python bridge, an AI classification engine, and a live command center — with staged detection zones (CLEAR, MONITOR, WARNING, THREAT) and automated countermeasure logic. Roadmap includes ESP32-CAM integration, multi-sensor networks, SDR (RTL-SDR / HackRF), and computer vision.

Key Features:

  • Arduino sensor array with staged detection zones
  • Python bridge for real-time data streaming
  • AI-based threat classification
  • Live command center dashboard
  • Firestore-backed cloud logging
  • Roadmap: ESP32-CAM, SDR, computer vision
